# BI & Analytics

Esta seção do projeto contém análises desenvolvidas no Looker Studio utilizando os dados do banco PostgreSQL Pokémon VGC Database.

## Dashboards desenvolvidos

- Top 10 Pokémon mais rápidos do tipo Fire
- Top 10 Pokémon mais rápidos do tipo Rock

## Objetivo

Explorar visualmente métricas competitivas de Pokémon utilizando conceitos de Business Intelligence e análise de dados.
